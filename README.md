# программа для учета видеоигр

## Назначение
Приложение для учета видеоигр, облегчающее поиск среди игр занесенных в некий список.
## Целевая аудитория
Люди, увлекающиеся видеоиграми.
## Предметная область
Неупорядоченный список видеоигр.
## Основные сущности
- игра
- платформа
- статус
## Основные функции
- выведение списка игр
- создание записи игры
- удаление записи игры
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
